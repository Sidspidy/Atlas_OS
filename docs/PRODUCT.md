# Atlas OS — Product Specification

## 1. Vision & Identity

Atlas OS is a premium personal AI desktop companion that lives on the user's computer. It understands the user's local files, projects, code, applications, terminal, browser, documents, voice, and workflows, assisting with or executing actions with explicit user permissions.

- **Product Name:** Atlas OS
- **Tagline:** "Your AI. Your computer. Always with you."
- **Core Concept:** An intelligent, living digital creature inside the user's computer. Unobtrusive when idle, proactive when helpful, and responsive to voice and input.

---

## 2. Modes of Operation

Atlas OS operates in two visual modes:

1. **Mode A — Full Application (Desktop OS Layer):**
   - Central AI Command Center, conversations, file explorer, project code view, memory hub, workflow builder, settings, and integrations.
   - Dark/Light themes with futuristic glassmorphism, subtle neon accents, and smooth motion.

2. **Mode B — Floating Companion:**
   - Frameless, transparent, always-on-top, draggable digital creature on the desktop.
   - Remains visible in top-right when the main app is minimized.
   - Quick command radial overlay upon click, ambient cursor awareness on hover, floating speech notifications for alerts.

---

## 3. Character & Digital Eyes Display System

Atlas is represented as a floating, fluffy digital creature with glowing ears and a dark glass digital display face.

### Atlas States & Digital Eyes
The face contains a digital eyes display reflecting Atlas's state machine:
- **IDLE:** Calm expressive eyes.
- **LISTENING:** Animated sound-wave bar eyes.
- **THINKING:** Scanning circles and pulsing dots.
- **SEARCHING:** Radar scanning sweep animation.
- **PLANNING:** Multi-node step dots.
- **WORKING:** Rotating progress ring / gear eyes.
- **SPEAKING:** Pulsing audio visualizer curves.
- **SUCCESS:** Glowing happy curved eyes / stars.
- **WARNING:** Exclamation indicator eyes.
- **ERROR:** Concerned expressions / red alert pulse.
- **SLEEP:** Closed sleepy digital arc eyes.
- **EXCITED:** High-brightness sparkling eyes.
- **PAUSED:** Static pause bars.
- **AWAITING_PERMISSION:** Shield / key lock indicator eyes.

---

## 4. Key Functional Capabilities

- **Local Filesystem Engine:** Fast background file indexing, semantic vector storage, project detection, and file watching.
- **RAG & Hybrid Retrieval:** Grounded Q&A over local files and code with citation links.
- **Code Intelligence:** Understands frameworks, symbol search, architecture explanation, and VS Code interaction.
- **Terminal Agent:** Safe process execution, sandboxed commands, risk-level classification, and permission prompts.
- **Voice System:** Natural wake word ("Hey Atlas"), speech-to-text, text-to-speech with interruption support.
- **Multimodal Screen Vision:** Screenshot capture and error analysis.
- **Workflow Automation:** Node-based workflow engine with trigger-action pipelines.
